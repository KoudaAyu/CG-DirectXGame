## 📌 STEP 1：全体のスライド構成（「図のページ」➔「動画のページ」）

「仕組み（図）」の次のページに「実際の映像（大画面動画）」を挟むことで、迫力と説得力が一番高まる構成になります。

```text

┌────────────────────────┐         ┌────────────────────────┐
│  5. 解決方法（CCD判定） │         │  【実機検証】すり抜けテスト │
├────────────────────────┤         ├────────────────────────┤
│                        │   次へ   │   ┌────────────────┐   │
│   [大きく図を配置]     │  ───▶   │   │                │   │
│   (fig05_ccd_solution) │         │   │   ▶ 大画面動画  │   │
│                        │         │   │                │   │
│   ・前フレームと今の点 │         │   └────────────────┘   │
│     を結ぶ線分で判定   │         │  ※ 弾速を上げても表面で確実  │
│                        │         │     に着弾・木片が飛散する   │
└────────────────────────┘         └────────────────────────┘
```

## 📌 STEP 3：動画専用スライドのレイアウト（おすすめデザイン）

動画を1ページ丸ごと使うスライドの作り方です。

1. **スライドのタイトル**:
   * 例：`【実機検証】高速連射時のすり抜け防止テスト`
2. **中央に動画を大きく配置**:
   * スライド中央に、横幅800〜900px程度（画面の約7〜8割）のサイズで大きく置く
3. **動画の下に「補足テキスト」を1行だけ中央揃えで置く**:
   * フォントサイズ: 18〜20pt
   * 文字色: 明るいグレー（`#A6B0BE`）または白
   * 内容: 「何が起きているか（検証できた結果）」を一言で書く

---

## 📌 STEP 4：PowerPointの必須設定（プロ見え3項目）

動画を貼ったら、以下の設定を行うと発表中にマウス操作が不要になります。

1. **自動再生にする**
   * 動画を選択 ＞ 上部「再生」タブ ＞ **開始を「自動」** に変更
2. **ループ再生にする**
   * 同じく「再生」タブ ＞ **「停止するまで繰り返す」にチェック**を入れる
3. **枠線をつけてスライドに馴染ませる**
   * 上部「ビデオ形式」タブ ＞ **ビデオの枠線**
   * 色：**ミントグリーン** または **青**
   * 太さ：**1.5 pt 〜 2 pt**
